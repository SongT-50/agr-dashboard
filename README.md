# 농가 경영진단 AI 대시보드

농촌진흥청 작목별 경영 데이터(2024, 29작목)를 기반으로 한 농가 경영진단·판매경로 컨설팅 대시보드.

- **데이터**: 농진청 농사로 작목별 평균 경영지표(공개 데이터)
- **기능**: 작목별 수익성 비교 · 내농가 진단 · 판매경로 진단(TOPSIS) · 공공데이터 카탈로그
- **운영**: 대전중앙청과(주) × 송자비스 AI 교차검증

## 보기

GitHub Pages: https://songt-50.github.io/agr-dashboard/

스마트폰에서 "홈 화면에 추가"하면 앱처럼 아이콘으로 실행됩니다 (PWA).

## 로컬 실행

```bash
python -m http.server 8765
# http://localhost:8765/
```

데이터는 `fetch`로 로드되어 `file://` 직접 열기는 안 됩니다 (HTTP 서버 필요).

## 구조

- `index.html` — 단일 페이지 앱 (탭 기반)
- `data/income_2024.json` — 작목별 경영지표 (29작목, 단일 소스)
- `data/pubdata-catalog.json` — 공공데이터 카탈로그
- `data/rda-cases.sample.json` — 판매경로 진단 케이스 샘플
- `manifest.json` / `sw.js` — PWA (홈화면 설치 + 오프라인)
- `evidence.js` — 판매경로 진단 결과에 「같은 조건 농가는 실제로」 근거 카드를 덧붙인다 (기존 함수를 감싸기만 한다)
- `channel-explorer.js` — **「같은 조건 농가는」 탭** (2026-09-14 추가)

## 「같은 조건 농가는」 탭 — API 키 없이 즉답

기존 「판매경로 진단」은 ① 가상 농가 10건이거나 ② API 키를 넣어야 움직였다.
처음 열어 본 농가는 아무것도 못 보고 나간다. 이 탭은 **호출 없이 고르는 즉시** 실측 분포를 보여준다.

- 작목(55) · 시도 · 재배규모를 고르면 → 판매경로 분포 · 주채널별 소득률/단가지수 · **층화 매칭 비교** · 「옮겨 보면」 참고값 계산기
- 표본 수(n)를 언제나 함께 찍고, n<30이면 「표본 적음」을 명시한다
- **인과로 읽히지 않게** 세 군데에 못을 박아 두었다 — 왼쪽 경고 상자 · 주채널 표 각주 · 계산기 아래 붉은 상자

### 🔴 이 탭은 «공개 배포본에서는 안 보인다»
데이터가 `data/CONTEST-ONLY_agr_channel_evidence.json`(농진청 소득조사 반출분)인데,
반출 조건이 「참여 목적 외 사용 금지」라 `.gitignore`의 `CONTEST-ONLY_` 규칙으로 push가 막혀 있다.
`channel-explorer.js`는 **데이터를 못 받으면 탭 자체를 만들지 않는다.** 공개본에 빈 탭이 남지 않는다.
⇒ 공개 배포 여부는 별도 판단이 필요하다. 지금은 로컬과 경진대회 제출 맥락에서만 쓴다.

### index.html 변경분
`<script src="channel-explorer.js"></script>` **한 줄뿐**이다.
탭 버튼·내용·`switchTab` 처리는 전부 그 파일이 스스로 붙인다(원본 로직 불변).
